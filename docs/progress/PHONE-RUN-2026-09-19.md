# Phase 10 — what to run on the phone (2026-09-19)

Phone: Android 14/15, USB debugging on, phone UNLOCKED (PIN lock cannot be
dismissed by adb; the script says so instead of blaming the app).

## 1. Sign the newest CI artifact (the fix is in the app code)

CI uploads `opencode-android-unsigned-release` for the newest commit.
On the machine that holds the key:

    bash phase10/scripts/sign-release-local.sh <unsigned.apk>

## 2. Run the rewritten device script

    bash phase10/scripts/90-real-device-signed.sh --apk phase10/signing/<signed>.apk

  - first run takes a few minutes (payload extraction) — the script prints what
    it is waiting for and screenshots every step
  - extras: --cert-sha256 <fingerprint>, --skip-live, --timeout-scale 2

## 3. Send back the whole p10d-out/ bundle

    SUMMARY.txt        verdict list (P10D_* lines)
    screenshots/       one PNG per meaningful action, validated non-blank
    ui/                accessibility dump per step
    DIAGNOSIS.txt      written only when something fails
    visibility.log     the external-observer check of the project folder

That bundle is what turns the two "NOT TESTED" rows in Appendix A of
docs/progress/phase10-signing-publish-prep-report.md into TESTED (or into a
diagnosis worth trusting).

## 4. Optional, one line, answers "can anything else read my files?"

    bash phase10/scripts/92-workspace-visibility.sh --pkg io.github.mcyber12.opencode
